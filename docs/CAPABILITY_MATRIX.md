# ماتریس تطبیق رفتار سایت به اندروید Native

وضعیت «کدنویسی» **به‌معنی تکمیل، Build موفق یا آزمون دستگاه نیست**. وضعیت «باقی» یعنی نیاز توسعه/تأیید. کد مبنا در `api.php`، `lib.php` و `schema.sql` مرجع است.

| قابلیت | رفتار تأییدشده نسخه وب | معادل پیشنهادی/نوشته‌شده در Android | روش آزمون پذیرش | وضعیت |
|---|---|---|---|---|
| حساب مدیر | ایجاد نخستین مدیر هنگام نصب | ایجاد مدیر هنگام اولین اجرای برنامه | نصب تمیز، ایجاد حساب، بازگشایی مجدد | کدنویسی؛ آزمون دستگاه باقی |
| همکار و نقش‌ها | افزودن staff توسط admin | فرم کاربر محلی، بررسی role در AuthService | staff نتواند بازیابی/حذف/کاربر اضافه کند | کدنویسی؛ آزمون باقی |
| غیرفعال‌سازی/تغییر رمز | admin، session_version | افزایش نسخه نشست و بررسی در عملیات | قطع نشست پس از تغییر رمز یا وضعیت | کدنویسی؛ آزمون باقی |
| محدودسازی ورود | ۵ بار در ۱۵ دقیقه | شمارنده قفل محلی هر حساب | ۵ رمز غلط و ورود بعد از بازگشایی | کدنویسی؛ آزمون باقی |
| ثبت IMEI اول | اجباری، ۱۵ رقم | اجباری، Luhn و ۱۵ رقم | معتبر/غلط، فارسی/عربی | آزمون دودویی منطق انجام؛ UI باقی |
| IMEI دوم | اختیاری، ارتباط به گوشی | اختیاری با alias مستقل و یکتایی DB | خالی، معتبر، دو دستگاه متفاوت | کدنویسی؛ تست ابزار Room نوشته/اجرا نشده |

| وضعیت گوشی | new/used | آکبند/کارکرده، بدون مقدار خودکار | هر دو حالت، عدم انتخاب | کدنویسی؛ آزمون باقی |

| تاریخ معامله | شمسی رشته‌ای | Picker شمسی ICU؛ ISO محلی قابل مرتب‌سازی | سال کبیسه/مرز سال/منطقه زمانی | کدنویسی؛ تست دستگاه باقی |

| ورود پشتیبان JSON وب | مدیر؛ ۵۰۰۰، رد تکراری | ورود افزایشی فایل JSON از SAF | تکرار id، اختلاف Luhn/کد ملی | کدنویسی؛ آزمون باقی |

| اسکن جستجو | در بک‌اند تأیید نشد | اسکن و برگشت به فیلد جستجو | بازگشت بدون دستکاری فرم | کدنویسی؛ آزمون باقی |
| نسخه روشن/تیره | مرجع CSS مستقل | Material 3 + DataStore | تغییر تم و راه‌اندازی مجدد | کدنویسی؛ آزمون باقی |

**مبنای داوری:** هیچ ردیف دارای وضعیت «کدنویسی» به‌تنهایی معیار انتشار را تأمین نمی‌کند. خروجی Run روی دستگاه، تست‌های Connected، مرور مجوزهای نهایی و تست بازیابی با داده واقعی ضروری است.
