# راهنمای انتشار کافه‌بازار — نیازمند بررسی دوباره قوانین روز

## اطلاعات بسته توسعه‌ای

- عنوان: «دفتر آفلاین IMEI»
- شناسه فعلی: `ir.anishop.imei.offline` (**یکتایی آن در بازار بررسی نشده است**).
- نسخه: `0.1.0-dev`، کد نسخه ۱؛ نسخه عمومی باید پس از تأیید، مثلاً `1.0.0` شود.
- minSdk 26، targetSdk 35، compileSdk 35. الزام API بازار در روز انتشار مجدداً بررسی شود.
- Launcher icon برداری شامل طرح گوشی/شبکه آبی در بسته موجود است؛ لازم است بازبینی گرافیکی و خروجی ۵۱۲px نهایی انجام شود.
- Permission: `android.permission.CAMERA` **فقط برای اسکن دوربین**. `INTERNET` و `ACCESS_NETWORK_STATE` در Manifest صریحاً با `tools:node=remove` حذف شده‌اند. هیچ مجوز حافظه عمومی/موقعیت/مخاطبین درخواست نمی‌شود.

## ساخت Release قابل نصب

۱. پس از نصب Android Studio / SDK / Gradle و اجرای موفق Unit/Instrumented Test، VersionCode و VersionName انتشار را تنظیم کنید.

۲. از `keytool` روی رایانه مالک برنامه برای ساخت keystore امضا استفاده کنید؛ alias و رمزهای قوی را در فایل محرمانه بیرون مخزن بگذارید و امضای Play/Bazaar را با آن پیکربندی کنید. رمز یا فایل Keystore را داخل سورس/پشتیبان عمومی قرار ندهید.

۳. از `./gradlew :app:assembleRelease :app:bundleRelease` استفاده کنید و با `apksigner verify --verbose ...` امضای APK را وارسی کنید. بدون `signingConfig` معتبر APK ساخته‌شده امضای انتشار ندارد و نباید بارگذاری شود.

۴. APK را روی گوشی‌هایی با نسخه‌های هدف نصب کنید؛ خروجی AAB فایل نصب مستقیم نیست. سایت بازار هنگام نشر تعیین می‌کند APK یا AAB لازم است. کافه‌بازار پشتیبانی از AAB را اعلام کرده است؛ پذیرش نسخه فعلی تضمین نمی‌شود.

۵. هنگام کنترل قبل از ارسال: مانیفست نهایی، مجوزها، مقادیر امنیتی، Crash در حالت آفلاین، کارکرد اسکن در شرایط کم‌نور، آزمایش فایل پشتیبان و بازیابی امن، سازگاری Device و Migrationهای واقعی بررسی شوند.

۶. اسکرین‌شات‌های فروشگاه باید **از بیلد واقعی** گرفته شوند؛ تصاویر پوشه `reference/` موکاپ‌های طراحی و قابل معرفی به‌عنوان عکس عملکرد واقعی نیستند. برای گرفتن عکس واقعی در بیلد تست باید موقتاً `FLAG_SECURE` غیرفعال شود، سپس Release دوباره با آن فعال ساخته و بررسی گردد.

## متون اولیه معرفی

**معرفی کوتاه:** دفتر مستقل خرید و فروش گوشی با ثبت آفلاین IMEI، جستجو و پشتیبان امن؛ فارسی و مناسب فروشگاه موبایل.

**معرفی مفصل (بعد از تأیید آزمون):** «دفتر آفلاین IMEI برای ثبت و پیگیری معاملات خرید و فروش گوشی روی خود دستگاه طراحی شده است. IMEI اول و دوم، اطلاعات طرف معامله، تاریخ شمسی و تاریخچه تغییرات در بانک اطلاعاتی خصوصی برنامه نگهداری می‌شوند. اسکن بارکد روی گوشی انجام می‌شود و برای قابلیت‌های اصلی به اینترنت یا سرویس خارجی نیاز نیست. پشتیبان قابل حمل با رمز عبور محافظت می‌شود. نقش مدیر و همکار برای دسترسی بخش‌های حساس پیش‌بینی شده است.» **این متن فعلاً برای نسخه توسعه‌ای است و قبل از نشر باید با عملکرد واقعی Release تطبیق داده شود.**

## فهرست کتابخانه‌ها و مجوزها

AndroidX Activity, Lifecycle, Room, Navigation, DataStore, CameraX, Jetpack Compose, Material3: مجوز Apache-2.0 (بازبینی فایل‌های POM/LICENSE هر نسخه هنگام انتشار لازم است). Google ML Kit Barcode Scanning نسخه بسته‌شده (بدون درخواست دانلود مدل): شرایط مجوز ML Kit/Google و مجوزهای transitive باید هنگام انتشار بازبینی شوند. Kotlin/Coroutines: Apache-2.0. JUnit: EPL-1.0. فونت جداگانه بسته‌بندی نشده و در UI فونت پیش‌فرض دستگاه مصرف می‌شود.

## وضعیت آخرین الزامات بازار

به سند **رسمی و روزآمد** پنل توسعه‌دهندگان کافه‌بازار مراجعه کنید و محدودیت‌های مجوز/حریم خصوصی/سنجه‌های فنی/نسخه API و قراردادها را بررسی کنید. در این خروجی هیچ مدرکی مبنی بر پذیرش انتشار یا تأیید صحت سیاست روز ثبت نشده است.
