# ساخت فایل APK نصب‌شدنی برای آزمایش

> در تاریخ ۱۴۰۵/۰۷/۲۴ فایل APK در این محیط ساخته نشده است: Android SDK و Gradle روی ماشین حاضر نصب نبودند و دانلود وابستگی‌ها به علت محدودیت شبکه ناموفق بود. بنابراین هیچ APK ساخته‌شده یا Build موفقی ادعا نمی‌شود.

## مسیر ساخت بدون نصب Android Studio، از طریق GitHub Actions

1. فایل `IMEI-Native-Source-with-APK-workflow.zip` را روی کامپیوتر استخراج کنید.
2. یک مخزن **خصوصی** GitHub برای سورس ایجاد کنید؛ محتوای داخل پوشه `IMEI-Native` (ازجمله `.github/workflows/build-debug-apk.yml`) را در شاخه `main` قرار دهید. **داده‌ها، رمزها، فایل keystore و اطلاعات مشتری را به مخزن اضافه نکنید.**
3. در GitHub به تب `Actions`، گردش‌کار `Build IMEI Debug APK` بروید و `Run workflow` را انتخاب کنید. با هر push روی main هم Build اجرا می‌شود.
4. پس از **موفقیت** Build، صفحه همان اجرا را باز کنید؛ از قسمت `Artifacts` فایل `IMEI-debug-apk` را دریافت کنید و فایل zip دانلودشده را باز کنید؛ `app-debug.apk` داخل آن است.
5. فایل `app-debug.apk` را به گوشی انتقال دهید و اجازه نصب از منبع انتخاب‌شده را فقط هنگام نصب بدهید. حداقل اندروید موردنیاز API 26 (Android 8.0) است.

## نکات مهم

- APK خروجی گردش‌کار **debug-signed** است و برای تست اولیه روی گوشی کاربرد دارد؛ **نسخه Release امضاشده برای انتشار در کافه‌بازار نیست**.
- ساخت، نصب و اجرای واقعی برنامه با این سورس هنوز تأیید نشده است؛ اگر Build شکست خورد، لاگ خطا از همان GitHub Actions لازم است تا خطاها اصلاح شوند.
- انتشار عمومی به آزمون‌های امنیت، پایگاه داده، پشتیبان‌گیری و دوربین و امضای انتشار با کلید اختصاصی نیاز دارد.
- فایل `gradle-wrapper.jar` همراه سورس قبلی موجود نبود؛ گردش‌کار حاضر برای جلوگیری از این مشکل Gradle 8.11.1 را مستقیماً نصب می‌کند. برای کار محلی باید Gradle 8.11.1 نصب یا wrapper معتبر ایجاد شود.
