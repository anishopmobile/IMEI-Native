# دفتر آفلاین IMEI — نسخه توسعه‌ای Android Native

> **وضعیت تحویل: سورس اولیه و مستندات؛ نه نسخه آماده انتشار.** این پروژه در محیط حاضر **Build اندروید، آزمون دستگاه و امضای Release نشده است**؛ بنابراین APK و AAB ارائه نمی‌شود. اطلاعات شش تصویر مرجع در `docs/reference/` نگهداری شده‌اند. هیچ داده نمونه ساختگی به پایگاه داده تزریق نمی‌شود.

## هدف و امکانات کدنویسی‌شده

پیاده‌سازی تک‌ماژولی Native Kotlin/Jetpack Compose با Room، MVVM، Navigation Compose، StateFlow، Coroutines، Material 3 و کاملاً فارسی/RTL. فرم خرید و فروش مجزا، جستجوی IMEI1/IMEI2، ثبت و ویرایش معامله، حذف منطقی/بازیابی مدیر، تاریخچه، گزارش فیلترشونده، مدیریت حساب مدیر/همکار، تاریخ شمسی ICU، اسکن آفلاین بارکد با CameraX/ML Kit، پشتیبان رمزنگاری‌شده، بازیابی اتمیک و ورود JSON خروجی نسخه وب به‌صورت افزایشی کدنویسی شده‌اند.

**هیچ WebView، Retrofit، اتصال PHP/MySQL، API سایت یا اجازه INTERNET تعریف نشده است.** `AndroidManifest` درخواست اینترنت ناشی از ادغام احتمالی کتابخانه‌ها را نیز حذف می‌کند. بعد از Build باید مانیفست نهایی و ترافیک روی دستگاه بررسی شوند؛ این ادعا جایگزین آزمون امنیتی نیست.

## اجرای پروژه روی رایانه دارای Android Studio

1. Android Studio نسخه سازگار با AGP **8.9.2**، **JDK 17**، Android SDK Platform **35** و Gradle **8.11.1** تهیه کنید. Kotlin **2.1.20** است.
2. پوشه `IMEI-Native/` را با گزینه **Open** باز و پروژه را Sync کنید. فایل‌های `settings.gradle.kts`، `build.gradle.kts` و `app/build.gradle.kts` موجودند.
3. **فایل اجرایی Gradle Wrapper و `gradle-wrapper.jar` در این بسته موجود نیستند.** در محیطی با Gradle 8.11.1، دستور `gradle wrapper --gradle-version 8.11.1` را برای تولید wrapper اجرا کنید؛ سپس `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:connectedDebugAndroidTest` را اجرا کنید. `connectedDebugAndroidTest` به دستگاه/شبیه‌ساز وصل نیاز دارد.
4. روی دستگاه با Android **8.0 (API 26)** یا جدیدتر آزمایش کنید. دلیل minSdk: تقویم ICU پایدار، Keystore و سازگاری مناسب؛ پوشش دستگاه‌ها باید با آمار مخاطبان بررسی شود.
5. در اجرای اول **حساب مدیر جدید** با نام، ایمیل، نام کاربری و رمز بسازید؛ رمز یا کاربر پیش‌فرض وجود ندارد. برای اسکن، مجوز دوربین در زمان انتخاب اسکن درخواست می‌شود.

## ساخت نسخه انتشار — فقط بعد از موفقیت آزمون‌ها

کلید Release را **در رایانه خودتان**، خارج از مخزن و با رمز جداگانه بسازید و پس از تکمیل تست به Gradle معرفی کنید. کلید امضا و رمز آن را در Git یا در این چت نفرستید. نسخه Release با `assembleRelease` و فایل AAB با `bundleRelease` ساخته می‌شود؛ در تنظیمات حاضر، نبود تنظیمات امضای نهایی به معنی **امضاشده نبودن** خروجی پیش‌فرض Release است. بسته کنونی APK یا AAB ندارد. برای جزییات `docs/RELEASE.md` را بخوانید.

## محدودیت‌های مهم

- این مرحله به Android SDK یا Gradle محلی دسترسی نداشت؛ خطاهای احتمالی Kotlin/Compose و ناسازگاری وابستگی‌ها باید در Build واقعی رفع شوند.
- رمزنگاری Android Keystore فقط برای **snapshotهای تاریخچه** است، نه کل دیتابیس. کد ملی، تماس و دیگر داده‌های معامله در Room خصوصی برنامه ولی به‌صورت متن عادی در فایل SQLite قرار دارند. پیش از عرضه عمومی درباره رمزنگاری کامل پایگاه داده تصمیم‌گیری و پیاده‌سازی/آزمون شود.
- خروجی JSON نسخه وب می‌تواند داده‌هایی داشته باشد که صرفاً از نظر طول IMEI یا کد ملی قبول شده‌اند؛ ورود در نسخه اندروید به علت اعتبارسنجی سخت‌گیرانه Luhn و رقم کنترلی کد ملی ممکن است رد شود. داده‌ها خودکار تغییر داده نمی‌شوند.
- منطق موجود سایت **کنترل گردش موجودی/عدم فروش دوباره** را اعمال نمی‌کند. اضافه کردن قانون تازه بدون تأیید کسب‌وکار می‌تواند معاملات قانونی را متوقف کند؛ بنابراین هنوز سیاست جدیدی تحمیل نشده است.
- تصاویر رابط، مرجع طراحی هستند؛ نمای کدنویسی‌شده مشابه‌سازی مفهومی است، نه اجرای پیکسل‌به‌پیکسل.
- فونت فارسی خارجی بسته‌بندی نشده؛ Android از فونت فارسی سیستم استفاده می‌کند. برای انتشار نهایی فونت دارای مجوز و فایل OFL آن را اضافه کنید.
- قفل بیومتریک، Migration نسخه ۱ به نسخه بعد و تست کامل سخت‌افزار دوربین هنوز تکمیل/تأیید نشده‌اند.
